# TypeScript

## Objetivo

Aprender TypeScript como lenguaje principal para automatización, backend y tooling.

## Orden inicial

1. JavaScript vs TypeScript
2. Variables: `let` y `const`
3. Tipos primitivos
4. Arrays
5. Objects
6. Functions
7. Type aliases
8. Interfaces
9. Unions
10. Narrowing
11. Classes
12. Generics
13. Async/Await
14. Error handling
15. Modules

## Evidencia esperada

Cada bloque debe terminar en código ejecutable y una explicación propia.

## Aplicación HMS

Los ejemplos progresarán hacia entidades como `Guest`, `Room` y `Reservation`.
