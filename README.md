# Software Engineering Learning Lab

Este repositorio registra aprendizaje **práctico y verificable**. No es una colección de apuntes copiados.

## Objetivo

Aprender fundamentos de ingeniería de software mientras se construye evidencia útil para proyectos reales y para el Hotel Management System (HMS).

## Áreas

- `typescript/`
- `databases/`
- `sql/`
- `git-github/`
- `fundamentals/`
- `api/`
- `backend/`
- `testing/`
- `devops/`
- `ai-engineering/`

## Regla de evidencia

Un commit debe representar un avance real: práctica, ejercicio, prueba, diseño, documentación útil, corrección o refactor.

## Flujo

1. Estudiar un concepto.
2. Explicarlo con palabras propias.
3. Resolver una práctica aislada.
4. Aplicarlo al dominio hotelero cuando tenga sentido.
5. Commit pequeño y significativo.
6. Registrar dudas y repaso en Notion.

## Convención de commits

- `feat:` nueva funcionalidad o práctica útil
- `test:` pruebas
- `fix:` corrección
- `refactor:` mejora sin cambiar comportamiento
- `docs:` documentación
- `ci:` integración continua
- `chore:` mantenimiento
